# PG Estilo Rústico · App del taller

App para manejar pedidos, presupuestos, stock, clientes y gastos de PG Estilo Rústico.

- **App:** `index.html` (se instala en el celular como aplicación).
- **Datos:** Firebase Firestore, protegidos con inicio de sesión de Google (`firestore.rules`).
- **Configuración:** `firebase-config.js`.
